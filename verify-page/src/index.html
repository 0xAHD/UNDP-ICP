Paste the document instead

The document is hashed locally and only the resulting digest is sent. When a credential link is opened, the document travels in the part of the URL after the hash symbol, which browsers do not transmit to any server. The signature is checked against the issuer key held by the registry, so verification relies on the network's consensus rather than on this website.
